# 🐊 Crocodile

A static, self-paced AI engineering learning tool generated from `AI-roadmap.yaml`.
No backend, no database — content is MDX in the repo, progress lives in your browser's
`localStorage`. See `../AI-engineering/static-plan.md` for the full design.

## Stack

- **Astro** (static site generation) + **React** islands for interactive bits
- **MDX** for lesson content (`src/pages/phase/**/*.mdx`)
- **Mermaid** for diagrams (`src/components/Mermaid.tsx`, rendered client-side)
- **Framer Motion** for progress bar / toggle animations
- **Pagefind** for build-time static search (only available after `npm run build`)

## Structure

```
src/
├── data/
│   ├── roadmap.yaml         # source of truth, copied from AI-engineering/AI-roadmap.yaml
│   └── roadmap-nav.json     # generated nav tree (do not hand-edit, regenerated by the script)
├── layouts/
│   ├── Base.astro           # HTML shell
│   └── Lesson.astro         # per-lesson chrome: sidebar, level tabs, progress toggle, resources
├── components/
│   ├── Sidebar.astro
│   ├── PhaseIndexPage.astro
│   ├── Mermaid.tsx
│   ├── ProgressToggle.tsx
│   └── PhaseProgressBar.tsx
├── lib/progress.ts          # localStorage read/write helpers
└── pages/
    ├── index.astro          # dashboard
    ├── search/index.astro
    └── phase/{phaseSlug}/
        ├── index.astro                       # generated, one per phase
        └── {topicSlug}/{level}.mdx            # generated placeholders — replace with real content
```

## Commands

| Command | Action |
|---|---|
| `npm run dev` | Regenerates content scaffold, then starts dev server at `localhost:4321` (search unavailable in dev) |
| `npm run build` | Regenerates content scaffold, builds to `dist/`, then builds the Pagefind search index |
| `npm run preview` | Serves the production build (search works here) |
| `npm run generate:content` | Re-parses `src/data/roadmap.yaml` and scaffolds any missing lesson MDX files — never overwrites existing ones |

## Writing lesson content

Each topic has three files: `beginner.mdx`, `intermediate.mdx`, `expert.mdx`, under
`src/pages/phase/{phaseSlug}/{topicSlug}/`. Edit the placeholder text directly — frontmatter
already wires up the layout, level tabs, and progress tracking. To add a diagram:

```mdx
import Mermaid from "../../../../components/Mermaid.tsx";

<Mermaid client:visible code={`flowchart LR
  A[Start] --> B[Concept]
  B --> C[Practice]`} />
```

`src/pages/phase/phase-01-python-for-ai/python-advanced/{beginner,intermediate,expert}.mdx`
is fully written out as a reference example — copy its structure for new topics.

If you edit `AI-roadmap.yaml` (add/remove phases or topics), copy the updated file into
`src/data/roadmap.yaml` and re-run `npm run generate:content` — it will add new
placeholder pages without touching content you've already written.

## Deploying

`npm run build` produces a fully static `dist/` folder — deploy it to GitHub Pages,
Vercel, Netlify, or S3+CloudFront. No server or environment variables required.
