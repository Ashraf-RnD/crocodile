## The chain rule: derivatives of composed functions

Neural networks are deeply nested compositions of functions — a layer feeding into
another layer, feeding into a loss. The **chain rule** lets you compute the derivative
of a composition by multiplying the derivatives of each piece:

```
if y = f(g(x)), then dy/dx = f'(g(x)) · g'(x)
```

```python
# f(x) = (3x + 1)^2 — a composition of g(x) = 3x+1 and f(u) = u^2
# by hand: dy/dx = 2(3x+1) * 3
def dy_dx(x):
    u = 3 * x + 1
    return 2 * u * 3

dy_dx(2)  # 42
```

This is precisely **backpropagation**: computing gradients through a deep network by
repeatedly applying the chain rule, layer by layer, from the loss back to the inputs.

## Automatic differentiation vs. symbolic/numeric differentiation

- **Numeric** (finite differences, like the previous lesson's `(f(x+h)-f(x))/h`):
  simple, but slow and imprecise for many parameters
- **Symbolic**: derives an exact formula (like doing calculus by hand) — exact but
  can blow up in expression size for deep compositions
- **Automatic differentiation (autograd)**: what PyTorch/TensorFlow actually use —
  builds a computation graph during the forward pass and applies the chain rule
  mechanically backward through it, giving exact gradients efficiently at any scale

```python
import torch
x = torch.tensor(2.0, requires_grad=True)
y = (3 * x + 1) ** 2
y.backward()
print(x.grad)  # tensor(42.) — autograd computed the same chain-rule result
```

## Common derivative rules used constantly in ML

| Function | Derivative | Where it shows up |
|---|---|---|
| `x^n` | `n·x^(n-1)` | Polynomial loss terms |
| `e^x` | `e^x` | Softmax, exponential decay schedules |
| `ln(x)` | `1/x` | Cross-entropy loss |
| `sigmoid(x)` | `sigmoid(x)·(1-sigmoid(x))` | Logistic regression, gates in LSTM |
