## Grouping people at a party

Imagine a party with no name tags and no assigned tables. You want to split
the crowd into `K` friend groups just by looking at where people are standing.
Drop `K` imaginary "centers" onto the floor at random. Everyone walks to
their nearest center. Once the groups settle, each center slides to the
average position of the people who joined it. Everyone re-checks which
center is now closest, and the process repeats until nobody switches groups
anymore.

That's K-Means. There are no labels telling you who belongs where —
it's **unsupervised learning**. The algorithm just needs the coordinates
(the features) and a number `K` for how many groups to form. It alternates
between two steps: assign each point to its nearest center, then recompute
each center as the mean of its assigned points.

## A tiny example

```python
import numpy as np
from sklearn.cluster import KMeans

# Six points that clearly form two groups
X = np.array([
    [1, 2], [1.5, 1.8], [1, 0.6],
    [9, 11], [8, 9], [9.5, 10],
])

model = KMeans(n_clusters=2, n_init="auto", random_state=42)
model.fit(X)

print(model.labels_)          # which cluster each point landed in
print(model.cluster_centers_) # the final centroid coordinates
```

Output looks like:

```
[0 0 0 1 1 1]
[[1.16 1.47]
 [8.83 10.0]]
```

Two clean clusters, matched to the two obvious blobs of points.

## Using make_blobs and predicting new points

`KMeans` can also be trained on generated data, then used to classify
points it has never seen:

```python
from sklearn.datasets import make_blobs
from sklearn.cluster import KMeans

X, _ = make_blobs(n_samples=300, centers=3, random_state=0)

model = KMeans(n_clusters=3, n_init="auto", random_state=0)
model.fit(X)

new_point = [[0, 0]]
print(model.predict(new_point))  # which of the 3 clusters it's closest to
```

`predict` just measures distance to each centroid and returns the nearest
one — no retraining needed.

## Try it yourself

Given these 2D points, use `KMeans` to split them into 2 clusters and print
the cluster label for each point:

```python
X = [
    [1, 1], [1.2, 1.1], [0.8, 0.9],
    [10, 10], [10.2, 9.8], [9.9, 10.1],
]
```

<details>
<summary>Solution</summary>

```python
from sklearn.cluster import KMeans

X = [
    [1, 1], [1.2, 1.1], [0.8, 0.9],
    [10, 10], [10.2, 9.8], [9.9, 10.1],
]

model = KMeans(n_clusters=2, n_init="auto", random_state=0)
model.fit(X)

print(model.labels_)
# e.g. [0 0 0 1 1 1] -- the first three points form one cluster,
# the last three form the other.
```
