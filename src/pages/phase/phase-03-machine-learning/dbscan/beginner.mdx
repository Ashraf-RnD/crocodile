## Finding crowds in a park

Imagine standing above a park, looking down at where people are sitting. Some
spots are packed — a crowd around a street performer, a group having a
picnic. Other spots have just one or two people scattered on the grass with
nobody nearby.

**DBSCAN** (Density-Based Spatial Clustering of Applications with Noise)
finds clusters the same way you would: it looks for regions where points are
packed closely together. Any region dense enough becomes a cluster. Points
that don't belong to any dense region are labeled **noise** — DBSCAN doesn't
force every point into a group.

This is different from **K-Means**, which needs you to say up front how many
groups (`K`) you expect, and which draws roughly circular clusters around
centers. DBSCAN doesn't ask "how many clusters?" — it asks "how packed does
an area need to be to count as a cluster?" That means it can find clusters of
any shape, and it won't drag an obvious outlier into the nearest group just
because K-Means needs it to be *somewhere*.

## A quick example

```python
from sklearn.cluster import DBSCAN
from sklearn.datasets import make_moons

# Two crescent (moon) shapes -- not spherical, K-Means struggles here
X, _ = make_moons(n_samples=200, noise=0.05, random_state=42)

model = DBSCAN(eps=0.2, min_samples=5)
labels = model.fit_predict(X)

print(set(labels))        # cluster ids found, e.g. {0, 1}
print(sum(labels == -1))  # number of points marked as noise
```

`eps` is how close two points must be to count as "neighbors." `min_samples`
is how many neighbors a point needs (including itself) to be considered part
of a dense region. Points labeled `-1` are noise.

Compare with K-Means on the same data:

```python
from sklearn.cluster import KMeans

km = KMeans(n_clusters=2, n_init=10, random_state=42).fit(X)
print(set(km.labels_))  # {0, 1} -- but the split cuts straight through
                         # the crescents instead of following their shape
```

K-Means slices the moons with a straight boundary because it only knows how
to build round clusters around centers. DBSCAN follows the curve of the
crescents because it just keeps growing a cluster through connected dense
regions, whatever shape that takes.

## Try it yourself

Using `make_blobs` from `sklearn.datasets`, generate 3 blobs of points plus a
few random outlier points scattered far away. Run `DBSCAN` on the combined
data and check that:

1. The 3 blobs are recovered as 3 separate clusters.
2. The scattered outliers are labeled `-1` (noise).

<summary>Solution</summary>

```python
import numpy as np
from sklearn.cluster import DBSCAN
from sklearn.datasets import make_blobs

# 3 well-separated blobs
X, _ = make_blobs(n_samples=150, centers=3, cluster_std=0.6, random_state=0)

# a handful of scattered outliers far from any blob
rng = np.random.RandomState(0)
outliers = rng.uniform(low=-10, high=10, size=(6, 2))

X_all = np.vstack([X, outliers])

model = DBSCAN(eps=0.8, min_samples=5)
labels = model.fit_predict(X_all)

print("clusters found:", set(labels) - {-1})
print("noise points:", sum(labels == -1))  # should be close to 6
```
