## The line of best fit

Imagine plotting house size (square footage) on the x-axis and sale price on the y-axis for a
bunch of houses. The points scatter, but roughly trend upward — bigger houses tend to cost more.
Linear regression finds the single straight line that best fits that trend, so you can predict a
price for a house you haven't seen yet just from its size.

That line is defined by two numbers: a slope (how much price increases per extra square foot) and
an intercept (the baseline price at zero square feet). Fitting a linear regression model just
means finding the slope and intercept that make the line's predictions as close as possible to
the actual data points, on average.

## A tiny example

```python
import numpy as np
from sklearn.linear_model import LinearRegression

# Square footage (feature) and price in $1000s (target)
X = np.array([[650], [800], [1200], [1500], [1800], [2200]])
y = np.array([120, 150, 210, 260, 300, 360])

model = LinearRegression()
model.fit(X, y)

print("slope:", model.coef_[0])
print("intercept:", model.intercept_)

# Predict the price of an 1,600 sq ft house
predicted_price = model.predict([[1600]])
print("predicted price ($1000s):", predicted_price[0])
```

`model.coef_` holds the slope(s) and `model.intercept_` holds the intercept — together they
define the line `y = coef * X + intercept`. `.fit()` does the work of finding the best line;
`.predict()` uses it.

You can check how well the line fits with `.score()`, which returns R², a number from roughly 0
to 1 where 1 means the line explains the data perfectly:

```python
print("R^2:", model.score(X, y))
```

## Try it yourself

Given hours studied and exam scores below, fit a linear regression model and predict the score
for someone who studies 5.5 hours.

```python
hours = [[1], [2], [3], [4], [6], [8]]
scores = [42, 51, 60, 68, 82, 95]
```

<details>
<summary>Solution</summary>

```python
from sklearn.linear_model import LinearRegression

hours = [[1], [2], [3], [4], [6], [8]]
scores = [42, 51, 60, 68, 82, 95]

model = LinearRegression()
model.fit(hours, scores)

predicted = model.predict([[5.5]])
print("predicted score:", predicted[0])
print("slope:", model.coef_[0], "intercept:", model.intercept_)
```

</details>
