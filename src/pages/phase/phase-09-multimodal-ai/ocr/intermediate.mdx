## Beyond image_to_string: getting structure, not just text

Production OCR pipelines rarely want just a text blob — they want *where* each word is,
plus a confidence score they can use to decide whether a human needs to check the
result. `pytesseract.image_to_data` gives you both:

```python
import pytesseract
from pytesseract import Output

data = pytesseract.image_to_data(image, output_type=Output.DICT)

for i, word in enumerate(data["text"]):
    if word.strip() and int(data["conf"][i]) > 60:
        x, y, w, h = data["left"][i], data["top"][i], data["width"][i], data["height"][i]
        print(f"{word!r} at ({x},{y}) conf={data['conf'][i]}")
```

That bounding box + confidence pair is what lets a downstream system draw a box around
a low-confidence field on a document review UI, or auto-approve high-confidence fields
without a human ever looking at them.

## A realistic document pipeline

Real OCR systems (invoice processors, ID scanners, receipt parsers) are rarely "load
image → run OCR". They're a preprocessing pipeline that exists almost entirely to make
Tesseract's job easier:

Deskewing matters more than most people expect — Tesseract's accuracy falls off sharply
once text is rotated more than a few degrees:

```python
import cv2
import numpy as np

def deskew(gray_img):
    coords = np.column_stack(np.where(gray_img < 255))
    angle = cv2.minAreaRect(coords)[-1]
    angle = -(90 + angle) if angle < -45 else -angle
    (h, w) = gray_img.shape
    M = cv2.getRotationMatrix2D((w // 2, h // 2), angle, 1.0)
    return cv2.warpAffine(gray_img, M, (w, h), flags=cv2.INTER_CUBIC,
                           borderMode=cv2.BORDER_REPLICATE)
```

## Language and layout hints improve accuracy

Tesseract accepts a `lang` parameter and page segmentation mode (`--psm`) that tells it
what kind of layout to expect — a single line, a sparse block, a full page of columns.
Getting this right is often a bigger accuracy win than any image cleanup:

```python
# Multi-language document, treat as a single uniform block of text
text = pytesseract.image_to_string(cleaned, lang="eng+fra", config="--psm 6")
```

In production, most teams route documents through a **confidence gate**: fields above a
threshold (e.g. 85) go straight into the database, fields below it get flagged for a
human reviewer. This "human-in-the-loop" pattern is standard for anything with financial
or legal consequences — full automation isn't the goal, cheap automation of the easy 90%
is.
