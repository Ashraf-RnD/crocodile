## Teaching by example

A base pretrained model has read a huge slice of the internet and learned to predict
"what word comes next" extremely well — but that's all it knows how to do. Ask it a
question and it might continue the sentence with more questions, instead of an answer,
because that's a very normal thing to see in raw internet text.

**Supervised Fine-Tuning (SFT)** fixes this the same way you'd teach a person a new
skill: show it lots of worked examples of the behavior you actually want. You collect a
dataset of `(prompt, ideal response)` pairs and keep training the model — same
next-token-prediction objective as pretraining, just on curated examples of the target
behavior instead of raw web text.

```python
examples = [
    {"prompt": "What's the capital of France?", "response": "The capital of France is Paris."},
    {"prompt": "Summarize: The cat sat on the mat.", "response": "A cat is sitting on a mat."},
    # ... thousands more
]
```

After enough examples like this, the model learns the *pattern* — answer directly,
stay on topic, stop when done — not just those specific answers.

### A minimal SFT example with Hugging Face TRL

```python
from datasets import Dataset
from trl import SFTTrainer, SFTConfig
from transformers import AutoModelForCausalLM, AutoTokenizer

model = AutoModelForCausalLM.from_pretrained("gpt2")
tokenizer = AutoTokenizer.from_pretrained("gpt2")

data = Dataset.from_list([
    {"text": "### Question: What is 2+2?\n### Answer: 4"},
    {"text": "### Question: What color is the sky?\n### Answer: Blue"},
])

trainer = SFTTrainer(
    model=model,
    train_dataset=data,
    args=SFTConfig(output_dir="./sft-out", num_train_epochs=3, per_device_train_batch_size=2),
)
trainer.train()
```

The `SFTTrainer` handles tokenizing the text, batching, and running the standard
training loop — you supply the model and the examples.

### Where SFT fits in the bigger picture

SFT is usually the *first* fine-tuning step after pretraining, and it's often followed
by preference-based tuning (see [RLHF Concepts](/phase/phase-10-fine-tuning/rlhf-concepts/beginner)
and [DPO](/phase/phase-10-fine-tuning/dpo/beginner)) to further refine style and
helpfulness. SFT teaches the model *what a good answer looks like*; those later steps
teach it to prefer *better* answers among several good ones.

## Try it yourself

You want to fine-tune a model to always answer in JSON format. Write one example
dictionary (`prompt`, `response`) that would help teach this behavior.

<details>
<summary>Solution</summary>

```python
example = {
    "prompt": "What is the capital of Japan?",
    "response": '{"answer": "Tokyo"}',
}
```

The key idea: your examples must consistently demonstrate the exact format and
behavior you want — the model learns by pattern-matching the training examples, so
inconsistent examples produce inconsistent behavior.
