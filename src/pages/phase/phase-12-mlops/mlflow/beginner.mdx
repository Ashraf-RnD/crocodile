## Why MLflow exists

Imagine training 30 versions of a model over a week, tweaking the learning rate,
swapping datasets, trying different feature sets. A few days later someone asks
"which run got 94% accuracy, and what parameters did it use?" Without a system,
the answer lives in your memory, a messy spreadsheet, or nowhere at all.

**MLflow** is an open-source tool that automatically logs every training run —
its parameters, metrics, and output files — so you can always answer that
question. Think of it as a lab notebook that fills itself in.

MLflow has four main pieces, but as a beginner you'll mostly touch two:

- **Tracking** — logs parameters, metrics, and files ("artifacts") for each run
- **Model Registry** — a versioned catalog of models ready for deployment

### Logging your first run

import mlflow

mlflow.set_experiment("iris-classifier")

with mlflow.start_run():
    learning_rate = 0.01
    n_estimators = 100

Run this a few times with different values, then launch the local dashboard:

```bash

```

Open `http://localhost:5000` and you'll see every run listed side by side —
parameters, metrics, and a way to sort by accuracy to find your best one.

## Try it yourself

You're training a model with three attempts and want to know which had the
best accuracy. Write the MLflow logging code for one run with `epochs=10`,
`batch_size=32`, and a final `accuracy=0.87`.

<details>
<summary>Solution</summary>

```python
import mlflow

mlflow.set_experiment("my-experiment")

with mlflow.start_run():
    mlflow.log_param("epochs", 10)
    mlflow.log_param("batch_size", 32)

    # ... training happens here ...

    mlflow.log_metric("accuracy", 0.87)
```

Run `mlflow ui` afterward and the run appears automatically — no manual
spreadsheet needed.
