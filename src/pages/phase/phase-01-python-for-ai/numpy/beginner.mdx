## Why not just use Python lists?

Every tensor, image, embedding, and dataset in AI is, underneath, a grid of numbers.
Python lists can hold numbers too, but they're slow for math and don't understand
"do this to every element at once." **NumPy** gives you the `array` — a fixed-type,
densely packed grid of numbers — plus fast, C-speed operations on the whole grid at
once. This is called **vectorization**, and it's the single habit that makes NumPy
(and by extension PyTorch/TensorFlow, which copy its API) fast.

```python
import numpy as np

# A Python list needs a loop to square every element
prices = [10, 20, 30, 40]
squared = [p ** 2 for p in prices]

# A NumPy array does it in one shot, no loop
prices_np = np.array([10, 20, 30, 40])
squared_np = prices_np ** 2
print(squared_np)  # [ 100  400  900 1600]
```

Same result, but the NumPy version runs as compiled C code under the hood instead of
a Python `for` loop — for a few numbers you won't notice, but for a million-row
dataset the difference is seconds versus milliseconds.

### Arrays have a shape

Everything in NumPy is described by its **shape** — how many rows, columns, etc.
This is the same concept as a tensor's shape in PyTorch.

```python
a = np.array([1, 2, 3])          # shape (3,)   — a vector
b = np.array([[1, 2], [3, 4]])   # shape (2, 2) — a matrix

print(a.shape)  # (3,)
print(b.shape)  # (2, 2)
```

### Basic math and indexing

```python
temps = np.array([68, 72, 75, 80, 65])

print(temps.mean())     # 72.0
print(temps.max())      # 80
print(temps[0])         # 68  — first element
print(temps[-1])        # 65  — last element
print(temps[temps > 70]) # [72 75 80] — boolean filtering
```

That last line — filtering an array with a condition — is used constantly in AI
workflows to select rows, mask out invalid values, or threshold predictions.

## Try it yourself

Given `scores = np.array([55, 82, 91, 40, 67, 100])`, write one line of NumPy that
returns only the scores that are 60 or above.

<details>
<summary>Solution</summary>

```python
import numpy as np

scores = np.array([55, 82, 91, 40, 67, 100])
passing = scores[scores >= 60]
print(passing)  # [ 82  91  67 100]
```
