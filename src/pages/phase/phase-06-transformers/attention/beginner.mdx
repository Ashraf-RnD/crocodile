## The idea: not every word matters equally

When you read the sentence "The trophy didn't fit in the suitcase because **it** was
too big," you instantly know "it" refers to the trophy, not the suitcase. Your brain
weighs some earlier words more heavily than others to resolve "it." That weighing
process — deciding how much each other word matters for understanding the current
one — is exactly what **attention** does in a neural network.

Before attention, models like RNNs processed text one word at a time and had to
squeeze the entire sentence's meaning into a single fixed-size memory vector by the
time they reached the end. Attention instead lets the model look back at *every* word
directly and decide, per word, how relevant each other word is right now.

### Query, Key, Value — a librarian analogy

Attention is usually described with three vectors per word:

- **Query** — "what am I looking for?" (from the word currently being processed)
- **Key** — "what do I contain?" (a label on every word, including this one)
- **Value** — "what information do I actually give you if picked?" (the payload)

Think of a library: your **query** is your research question, every book has a
**key** (its catalog description), and the **value** is the book's actual content.
You compare your query against every key to find the most relevant books, then read
mostly from the most relevant ones (weighted by relevance) and a little from the rest.

### A tiny worked example

```python
import numpy as np

# 3 words, each represented as a 4-dim vector (toy example)
query = np.array([1.0, 0.0, 1.0, 0.0])          # the word "it"
keys = np.array([
    [1.0, 0.0, 1.0, 0.0],   # "trophy" — similar to query
    [0.0, 1.0, 0.0, 1.0],   # "suitcase" — different from query
    [0.2, 0.1, 0.9, 0.0],   # "fit" — somewhat similar
])
values = np.array([
    [10.0, 0.0],   # meaning payload for "trophy"
    [0.0, 10.0],   # meaning payload for "suitcase"
    [5.0, 5.0],    # meaning payload for "fit"
])

# 1. Score: how well does the query match each key?
scores = keys @ query

# 2. Turn scores into weights that sum to 1
def softmax(x):
    e = np.exp(x - np.max(x))
    return e / e.sum()

weights = softmax(scores)
print("attention weights:", weights)

# 3. Blend the values using those weights
output = weights @ values
print("output:", output)
```

Run this and you'll see "trophy" gets by far the highest weight — the query for "it"
matches its key most closely, so the output leans heavily toward the trophy's value.
This is the entire mechanism: **score, normalize, blend**.

## Try it yourself

Change the `query` vector above to `[0.0, 1.0, 0.0, 1.0]` (matching "suitcase"
instead) and predict which word will dominate the output before running the code.

<details>
<summary>Solution</summary>

```python
query = np.array([0.0, 1.0, 0.0, 1.0])
# scores = keys @ query will now be highest for the "suitcase" key,
# so softmax(scores) puts most of its weight on index 1, and the
# output will be close to [0.0, 10.0] — the suitcase's value.
```

The key insight: attention weights shift entirely based on what the query "asks for" —
the same set of keys/values can produce very different outputs depending on the query.
