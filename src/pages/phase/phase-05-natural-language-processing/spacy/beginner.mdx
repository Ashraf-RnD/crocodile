## A toolkit for understanding sentence structure

**spaCy** is a Python library for practical, everyday NLP tasks: splitting text into
words, tagging each word's part of speech, finding names of people and places, and
figuring out how words relate to each other grammatically. Where Hugging Face
Transformers is about running big pretrained language models, spaCy is about fast,
reliable, "classic" text-processing pipelines.

Think of spaCy as a Swiss Army knife for text: one tool that reliably handles
tokenizing, tagging, and parsing sentences, so you don't have to write that logic
yourself.

### Your first spaCy pipeline

```python
import spacy

nlp = spacy.load("en_core_web_sm")  # a small pretrained English pipeline
doc = nlp("Apple is looking at buying a startup in San Francisco.")

for token in doc:
    print(token.text, token.pos_, token.dep_)
# Apple    PROPN   nsubj
# is       AUX     aux
# looking  VERB    ROOT
# at       ADP     prep
# buying   VERB    pcomp
# a        DET     det
# startup  NOUN    dobj
# in       ADP     prep
# San      PROPN   compound
# Francisco PROPN  pobj
# .        PUNCT   punct
```

Calling `nlp(text)` runs the whole pipeline at once (tokenizer, tagger, parser) and
returns a `Doc` object — every word becomes a `Token` with rich linguistic
information already attached.

### Finding named entities

```python
for ent in doc.ents:
    print(ent.text, ent.label_)
# Apple          ORG
# San Francisco  GPE   (geopolitical entity)
```

spaCy automatically recognizes people, organizations, locations, dates, and more —
this is called **named entity recognition (NER)**, and it's one of the most commonly
used spaCy features in real applications like resume parsing or news analysis.

## Try it yourself

Load `en_core_web_sm` and process the sentence
`"Barack Obama was born in Hawaii and became president in 2009."` Print out all the
named entities and their labels.

<details>
<summary>Solution</summary>

```python
import spacy

nlp = spacy.load("en_core_web_sm")
doc = nlp("Barack Obama was born in Hawaii and became president in 2009.")

for ent in doc.ents:
    print(ent.text, ent.label_)
# Barack Obama   PERSON
# Hawaii         GPE
# 2009           DATE
```
