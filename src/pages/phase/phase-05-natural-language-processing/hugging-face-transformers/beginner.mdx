## A library of pretrained models, ready to use

Training a language model from scratch takes enormous amounts of data and compute —
far more than almost anyone needs to do themselves. **Hugging Face Transformers** is
a Python library that gives you instant access to thousands of pretrained models
(BERT, GPT-2, RoBERTa, and many more) that you can download and use in a few lines of
code.

Think of it like a library of pre-built engines: instead of designing and machining
an engine from raw metal, you pick one off the shelf that already does what you need,
and bolt it into your car.

### The `pipeline` — the fastest way to get started

```python
from transformers import pipeline

classifier = pipeline("sentiment-analysis")
result = classifier("I absolutely loved this movie!")
print(result)
# [{'label': 'POSITIVE', 'score': 0.9998}]
```

Behind the scenes, `pipeline()` downloads a pretrained model and its matching
tokenizer, wires them together, and handles all the preprocessing/postprocessing for
you. There are pipelines for many tasks:

```python
summarizer = pipeline("summarization")
summary = summarizer(
    "Hugging Face Transformers is an open-source library that provides "
    "thousands of pretrained models to perform tasks on text, images, and "
    "audio. It has become one of the most widely used libraries in modern "
    "machine learning, powering research and production systems alike.",
    max_length=30, min_length=10,
)
print(summary[0]["summary_text"])

translator = pipeline("translation_en_to_fr")
print(translator("Hugging Face makes NLP accessible.")[0]["translation_text"])
```

### Choosing a specific model

By default `pipeline()` picks a reasonable model for you, but you can name one
explicitly from the Hugging Face Hub:

```python
classifier = pipeline(
    "sentiment-analysis",
    model="distilbert-base-uncased-finetuned-sst-2-english",
)
```

Every model on the Hub has a model card describing what it was trained on, its
intended use, and known limitations — always worth a quick read before relying on a
model in a real project.

## Try it yourself

Use a `pipeline("question-answering")` to answer a question given a short paragraph of
context.

<details>
<summary>Solution</summary>

```python
from transformers import pipeline

qa = pipeline("question-answering")
result = qa(
    question="Who created the Transformers library?",
    context="The Transformers library was created by Hugging Face, "
            "a company focused on open-source NLP tools.",
)
print(result)
# {'answer': 'Hugging Face', 'score': 0.9x, 'start': ..., 'end': ...}
```
